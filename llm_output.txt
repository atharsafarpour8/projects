1) LLM (Language Model Language) شامل مدل‌ها و تمرین‌های مربوط به زبان‌های مختلف است.

2) Local یک موقعیت یکی از مهم‌ترین جوانای قابلیت است.

3) API (Application Programming Interface) برای ارائه خدمات و روش‌های عملیاتی است.

4) 3 مزیت Local: ترجمه، تصاویر، و سوالات.

5) 3 مزیت API: شناسایی، تحلیل و تنظیمات.

مثال: لطفاً در مورد "چت‌بات" و "تولید متن" اطلاعات بفرمایید تا باشند.
